# SELFISH v2.0 — Personal Performance & Focus Operating System

A desktop productivity suite engineered in Python and Tkinter, designed for deep-work enforcement, distraction blocking, local encrypted data storage, and Claude AI assistance.

## Key Modules
- **Focus & Distraction Blocker:** Configurable Pomodoro work/break intervals, system-level website blocking, and application tracking.
- **Encrypted Local Vault:** SHA-256 hashed passphrase protection for sensitive notes, goals, and strategic plans.
- **Strategic Execution Tool:** 90-day activity tracking, startup integration, and Windows AppData storage.
- **Claude AI Integration:** Embedded AI co-pilot supporting execution workflows and strategic prompts.

## Files
- `SL_v2.py`: Main desktop GUI application and system event handlers.
- `sl_config.json`: Local system preferences and configuration state.
- `BUILD_EXE.bat`: Packaging script for Windows distribution.
